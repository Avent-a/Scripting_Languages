# 📜 Scripting Languages

Репозиторий с практическими работами и учебными проектами по курсу **«Скриптовые языки программирования»**. Здесь собраны примеры и лабораторные работы, демонстрирующие возможности JavaScript в связке с HTML и CSS — от базовых конструкций языка до интерактивных веб-страниц.

## 📂 Структура проекта

```
Scripting_Languages/
└── Done/          # Выполненные лабораторные / практические работы
```

Каждая работа в папке `Done` представляет собой отдельную мини-страницу или скрипт, иллюстрирующий определённую тему курса (работа с DOM, событиями, формами, стилизацией и т. д.).

## 🚀 Технологии

- **HTML5** — разметка страниц
- **CSS3** — стилизация интерфейса
- **JavaScript** — логика и интерактивность

## ▶️ Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/sollcoun/Scripting_Languages.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd Scripting_Languages
   ```
3. Откройте нужный `.html` файл в браузере (двойным кликом или через Live Server в VS Code).
